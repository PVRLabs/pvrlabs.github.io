# PVR Labs Static Hosting

This repository hosts public static resources maintained by [PVR Labs](https://github.com/PVRLabs).

It provides a lightweight, GitHub Pages-based distribution endpoint for Maven artifacts and other resources that benefit from stable public URLs.

## Hosted resources

| Path | Purpose | Source |
|---|---|---|
| [`/maven/`](https://pvrlabs.github.io/maven/) | Curated Maven repository for open-source Java libraries and preview releases | [PVR Labs Maven Repository](https://github.com/PVRLabs/maven-repo) |

Additional resources may be hosted here in the future.

## How it works

This repository contains published static files. Source code, submission rules, and publication tooling belong to their respective projects.

For Maven artifact submissions, documentation, and development, visit [PVRLabs/maven-repo](https://github.com/PVRLabs/maven-repo).
